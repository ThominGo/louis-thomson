# Louis Thomson

Site immersif du percussionniste et compositeur Louis Thomson : une scène de concert en nuage de points, à explorer et à jouer.

- `index.html` : le site (Three.js, GSAP, Web Audio)
- `stage.json` : la scène 3D exportée de Blender
- `layout_mobile.json` : la disposition portrait, exportée de la scène « LouisThomson_Mobile »

Le contenu est géré dans le back office de la version Claude, puis figé ici à chaque mise à jour.
